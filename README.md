# 스네이크 대결 🐍

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 스네이크. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다. 혼자 하는 클래식 `worm-game`(지렁이 게임)과는 별개입니다.

- 17x21 칸 판에서 두 마리 뱀이 **같은 순간에** 한 칸씩 움직인다(0.14초마다). 먹이(사과)가 늘 2개 있고, 먹으면 한 칸 길어진다
- 벽·내 몸·**상대 몸**에 머리를 부딪히면 진다. 머리끼리 부딪히거나 서로 자리를 바꾸며 지나가면 둘 다 진 것이라 무승부. 한 판이 700걸음을 넘으면 더 긴 쪽이 이긴다
- **3판 2선승**. 비긴 판은 점수 없이 다음 판으로 가고 5판까지 가도 안 나면 이긴 판이 많은 쪽(같으면 무승부)
- 시작은 0 번 뱀이 왼쪽 아래에서 위로, 1 번 뱀이 오른쪽 위에서 아래로 (판을 180도 돌리면 똑같아 공평). 화면은 늘 내 뱀이 왼쪽 아래에 오게 돌려 그린다
- 조작: 화살표·WASD, 화면 밀기(스와이프), 아래 방향 버튼. 바로 뒤로는 못 돌고, 한 걸음 사이에 눌러도 뒤로 도는 일이 없다. M 소리
- 컴퓨터: 쉬움은 먹이 쪽으로만 가고 가끔 엉뚱한 길로 가며, 어려움은 갈 수 있는 넓이를 재서 갇히지 않고 상대 머리와 마주칠 칸을 피한다 (어려움 대 쉬움 모의 대전 200판에서 어려움 158승 · 쉬움 17승 · 무승부 25)
- 컴퓨터를 이긴 횟수는 `snakebattleWins` (로비 표시용), 온라인 전적은 `snakebattleOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 기권 · 한 판 더(뱀 자리 교대). 서버가 같은 규칙(`public/logic.js`)으로 한 걸음씩 진행하고 매 걸음 뱀 몸·먹이를 보낸다. 서버는 방향(0~3)만 받아 규칙으로 검사한다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- 튜토리얼 중에는 처음 방향을 바꿀 때까지 판이 멈춰 있고, 져도 점수 없이 다시 시작한다

규칙·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭·진행은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(벽·몸·정면 충돌·자리 바꿈·꼬리 따라가기·먹이·시간 제한·같은 시드면 같은 판·컴퓨터 강약), `test/server.test.js`(매칭·프레임 전송·봇 두 명이 3판을 끝까지·기권·한 판 더·방 코드·재접속·입력 검사). 서버 시험은 `TICK_MS`·`BREAK_MS` 환경변수로 시간을 줄인다.
